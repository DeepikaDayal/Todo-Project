# Todo app
Todo Tracker is a simple yet powerful web app for managing daily tasks. It features a search bar for quick task lookup, an add task button that prevents duplicates, and real-time display of the current time and date.

Elaborate on features.  "Users can add tasks by clicking the button, mark them as complete or incomplete with tick/untick functionality, delete individual tasks via a cross button, or clear all tasks at once with the clear all button. Designed for productivity, it ensures no duplicate entries and keeps you aware of the time while staying organized.")

 "Ideal for personal use, work, or study—keep track of your to-dos without hassle.
# Features
Search Bar: Quickly find tasks by typing keywords.
Add Task Button: Adds new tasks; automatically prevents duplicates.
Current Time and Date Display: Shows live time and date for better context.
Tick/Untick Tasks: Mark tasks as done or undone with a simple click.
Delete Button: Remove individual tasks using the cross button.
Clear All Button: Instantly delete all tasks for a fresh start.
# Technologies Used
Frontend: HTML, CSS, JavaScript (or React/Vue for interactivity).
Other: Local Storage for saving tasks, or libraries like Moment.js for time/date.
# Usage
Open the app and view the current time/date.
Use the search bar to find tasks.
Click "Add Task" to enter a new task (duplicates are blocked).
Tick/untick to mark completion.
Use the cross button to delete a task or "Clear All" to remove everything.
